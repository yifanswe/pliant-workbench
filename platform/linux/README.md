# Linux platform adapter

**Responsibility:** provide Linux native-window, input, accessibility,
credential-facility, packaging, and update integration selected by public
platform interfaces.

**Boundary:** it hosts platform mechanisms, not browser UI policy or private
shortcuts for presets. Linux comes after macOS. Its UI toolkit, display-server
coverage, and minimum distributions are not chosen yet.

**Status:** scaffold only. See the [module map](../../MODULES.md).
